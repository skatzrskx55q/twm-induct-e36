# E36 · Самодостаточный исследовательский архив

## Статус
E36 — новый обучаемый кандидат, превосходит прежние модели на 16 знакомых законах, но **НЕ новый принятый baseline**: композиционные N39/N2 хуже алгоритмического E34, свежий слепой экзамен не проводился.

## Архитектура
PyTorch 2.x, sklearn для `e34_induction` и проверок, numpy, scipy по зависимостям, matplotlib только для отчёта. 42 748 параметров, попарные локальные признаки + обучаемое отображение, внутри каждого эпизода `ridge` по восьми реально наблюдавшимся переходам. Рёбра -> узлы, только собственный предсказанный граф. Формулы и `law_id` не используются ни в forward, ни в обучении. Метки следующих состояний используются только в loss обучающего запроса и в оценщике.

## Воспроизведение из распакованного ZIP

```bash
cd E36
python verify_manifest.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 python e36_independent_audit.py
# Повторное обучение всех трёх seed (перезаписывает результаты):
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 python e36_meta_ridge.py --steps 750 --seeds 17,29,43 --batch 16
# Открытый исторический N2, 16-шаговый автономный rollout:
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 python e36_n2_rollout.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 python e36_controls.py
```

`e36_independent_audit.py` (повторно обучает только seed17) проверяет сырые truth bits, профили, полные пары N39, все сохранённые N2 траектории и битовую идентичность seed17. При независимом аудите данные из `N2_PRIVATE_LABELS.jsonl` читаются **только для сопоставления с сохранённым прогнозом**, а не в модель.

## Источники сравнения
`E34/REF/E22_*` — исторические checkpoint и логиты E22; `E34/RESULTS/` — сохранённые результаты E34; `RESULTS/E35_*` — предыдущая нейронная E35-B и её checkpoint. `E34/INPUTS/` — известные train/val и парные истории; `E34/REF/TWM_N39/...` — открытые исторические контрфакты, N2 — исторически открытый 16-шаговый архив. Нового закрытого экзамена нет.

## Цепочка происхождения
E36 опирается на самодостаточный архив E35 и прежние архивы E34/E22. Никакие скрытые oracle-законы, ID в входе модели, метки будущего при инференсе не используются. Исходный архив E35 доступен в предыдущем выпуске проекта.

## Примечания
- Работа использует вручную заданные локальные структурные признаки как индуктивное смещение. Это не открытие абсолютно произвольных законов.
- Сравнение по количеству шагов/параметров между E22, E34, E35 и E36 не является равным по вычислительной стоимости.
- Критерий нового официального baseline требует отдельного закрытого экзамена новых композиций, сохранения старых навыков и H1/H4/H8/H16.
