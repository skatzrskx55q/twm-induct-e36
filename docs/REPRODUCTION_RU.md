# Руководство по воспроизведению

1. Установите зависимости по [README_RU](../README_RU.md). В среде подготовки проверялся только CPU.
2. `python verify_integrity.py` проверяет SHA-256 всех распространяемых исходных файлов без ML-зависимостей.
3. `python run.py check` выполняет `python verify_manifest.py` в `research/E36`. Код ошибки сохраняется, в том числе при провале теста.
4. `python run.py --keep ../experiment demo` выполняет `python e36_n2_rollout.py`. Копия данных и новые результаты остаются в `../experiment`. Перед длительным запуском прочитайте исходный README.
5. Обучение или расширенный эксперимент: `python e36_meta_ridge.py --steps 750 --seeds 17,29,43 --batch 16`. Работайте в отдельной копии, сохраняйте оригиналы и учитывайте условия исторического протокола и разблокировки EXAM. Не подбирайте параметры по опубликованным ответам EXAM. Для Bash может потребоваться Linux/WSL.

## Метрики
На открытых dev L2/L3 точные состояния H16: 84/240 и 108/240; CART сильнее на композиции. Интерпретируйте H90/H16 и точность конечного состояния/всей траектории по исходному протоколу, а не как единый benchmark. NLL: меньше — лучше. Исходные отчёты содержат знаменатели и отрицательные контроли.
